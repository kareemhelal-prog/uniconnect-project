# 🚀 Admin Dashboard - لوحة تحكم الأدمن

 لوحة التحكم الخاص بي. تم تصميم وتطوير هذه الصفحة لتكون واجهة برمجية متطورة تهدف إلى تسهيل إدارة البيانات وعرض الأنشطة الحيوية للمشروع بشكل مرئي وجذاب.

## 📋 وصف الصفحة (Page Overview)
تم تصميم الصفحة لتشمل أهم العناصر التي يحتاجها أي مسؤول نظام (Admin)، حيث تركز على:
* **تتبع النشاط (Activity Tracking):** نظام متكامل لعرض الإحصائيات اليومية.
* **تحليل البيانات:** واجهة رسومية توضح للمستخدم التطورات الزمنية والبيانات المعقدة بشكل مبسط.
* **سهولة التصفح:** تصميم عصري يعتمد على نظام المكونات (Components) لضمان سرعة الأداء.

## 🛠️ المميزات التقنية (Technical Features)
لقد استخدمت في هذا العمل مجموعة من أقوى تقنيات الويب:
1. **React.js:** لضمان بناء واجهة مستخدم تفاعلية وسريعة جداً.
2. **Chart.js Integration:** قمت بدمج المكتبة لعرض الرسوم البيانية المتطورة (Line Charts) مع تخصيص الألوان والخطوط لتناسب هوية المشروع.
3. **Responsive Design:** الصفحة مهيئة للعمل بكفاءة على جميع الشاشات (Desktop, Tablet, Mobile).
4. **Clean Code:** تم تنظيم الكود وفصل المكونات (src, public) لتسهيل عملية التطوير المستقبلية.

## 🔧 المكتبات التي تم تثبيتها
لقد قمت بإضافة المكتبات التالية لضمان عمل الرسوم البيانية:
* `chart.js`
* `react-chartjs-2`
